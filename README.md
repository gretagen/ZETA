ZETA (Zenith Energy Turbine Archiver) is a package manager written in Lua, it is the official package manager used in HaliadeOS.

It is incredibly verbose by design and is pretty quick and supports 3 package formats :

.debs (from debian)
pkg.tar.zst (from arch/artix)
and prebuilt tar.gz's and tar.xz.

it is incredibly lightweight and is constantly maintained and updated.
